## 🧩 About

**Among Us helpers** is a curated list of Among Us open-source tools:

- **Overlays** — on-screen helpers, layout notes, task tracker panel, role roster view
- **Quality-of-Life Helpers** — task list manager, map notes, lobby config notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Lobby Helpers
- Task Tracker Panel — review task progress in single-player study
- Role Roster View — inspect assigned roles in a private match
- Lobby Config Notes — organize settings for study sessions
- Speed Notes — record movement values for offline practice (0.1x to 5x)

### 🗺️ Map & overlay
- Map Overlay — on-screen map layout notes
- Vent Marker Notes — study vent placements on each map
- Player overlay Notes — track positions in a private practice room
- Sabotage Log — review event sequences for study

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Kill Cooldown Notes — manual cooldown tuning in a private match
- Emergency Meeting Notes — chain study scenarios in the editor

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"Among Us.exe"` | Target process |
